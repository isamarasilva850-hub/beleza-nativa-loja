## 🎓 COMO ESTUDAR PARA A DEMO

### 1️⃣ Memorize os 5 Diferenciais
```
✅ CRM Consultivo (7 etapas)
✅ Artes Prontas (Instagram-ready)
✅ Mensagens Consultivas (+50% vendas) ← DIFERENCIAL PRINCIPAL
✅ IA Bela (treina vendedor novo)
✅ Dashboard (KPIs em tempo real)
```

### 2️⃣ Estude os 3 Números Mágicos
```
30-50% = aumento de vendas esperado
R$ 599/mês = preço normal
R$ 2.000 = valor do setup (que sai grátis)
```

### 3️⃣ Domine as 3 Objeções Principais
```
❌ "Já temos um sistema"
✅ "Perfeito! PRÓ MAX complementa o que vocês têm"

❌ "Quanto custa?"
✅ "R$ 599/mês. Mas 1 revenda vendendo 10% a mais já paga."

❌ "E se não gostar?"
✅ "Teste 7 dias grátis. Sem cartão, sem compromisso."
```

## 💡 DICAS FINAIS DE APRESENTAÇÃO

### Abertura Poderosa
Não comece com "Então, deixa eu mostrar o PRÓ MAX..."  
Comece com: "Me diga uma coisa... você sabe qual das suas revendedoras vende mais?"

### Middle Game
Não fale em features (CRM, artes, etc)  
Fale em BENEFÍCIOS: "Você vai saber exatamente em qual fase cada revenda está"

### Fechamento Forte
Não pergunte "Vocês têm interesse?"  
Pergunte "Você prefere começar com teste de 7 dias ou já ativa com o cupom?"
