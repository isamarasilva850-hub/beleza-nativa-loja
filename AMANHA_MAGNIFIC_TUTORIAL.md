## 🎯 PASSO A PASSO (AMANHÃ)

### PASSO 1: Abrir o arquivo
```
1. Abra o arquivo PROMAX_DECK_HTML.html
2. Clique com botão direito
3. "Abrir com" → Chrome ou Firefox
4. Pronto! Deck abre no navegador
```

### PASSO 2: Ver os slides
```
- Use as setas ← → para navegar
- Ou clique nos botões "Anterior" / "Próximo"
- Total: 15 slides
```

### PASSO 3: Usar Magnific
```
1. Ative a extensão Magnific no navegador
2. Abra a página do deck
3. Use Magnific para:
   ✅ Melhorar cores (roxo + branco + dourado)
   ✅ Adicionar imagens/ícones
   ✅ Melhorar tipografia
   ✅ Deixar mais profissional
```

### PASSO 4: Exportar/Salvar
```
Após Magnific processar:
- Salve como PDF
- Ou print de cada slide
- Ou copie para PowerPoint/Canva
```
